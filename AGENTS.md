# Агент заявок на библиотеку

Прочитай README.md. Если пользователь просит доступ, проверь подключённый GitHub-аккаунт и существующую открытую заявку этого автора. Создай одну issue по шаблону .github/ISSUE_TEMPLATE/access-request.yml с меткой access-request только по поручению пользователя. Верни ссылку и объясни, что требуется одобрение владельца. Не запрашивай пароль или токен. Текст заявки публичный; исходные текстуры и рабочие материалы остаются в закрытой библиотеке.

Метка access-approved означает решение владельца о выдаче доступа. Ставь её только при явном поручении владельца одобрить конкретного заявителя; само поручение настроить систему не одобряет будущие заявки. Адресат приглашения всегда автор issue, никогда имя из текста или комментариев.

При изменении программы читай docs/design.md, запускай npm test и независимый AI-review. Работай в work/<author>/plant-library-access/<job>. Секрет LIBRARY_INVITE_TOKEN хранится только в GitHub Actions Secrets; сохранённые учётные данные Git не копируй в workflow. Библиотеку plant-texture-library и её карты не изменяй для проверки заявок.
