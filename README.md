# Доступ к библиотеке растений

[Отправить заявку](https://github.com/agnstrv/plant-library-access/issues/new?template=access-request.yml)

Это публичный приём заявок для закрытой библиотеки команды. Текстуры и пароли здесь не хранятся.

**Активация:** для реальных приглашений владелец должен один раз добавить secret LIBRARY_INVITE_TOKEN по инструкции ниже. До этого новые приглашения не отправляются.

## Коллеге

1. Войдите в GitHub под своим аккаунтом и отправьте заявку по ссылке выше.
2. Дождитесь одобрения владельца. Скрипт сам определяет ваш аккаунт по автору заявки — отдельно отправлять логин не нужно.
3. После сообщения «приглашение отправлено» примите его в уведомлениях GitHub или на почте. Закрытая заявка означает отправленное приглашение, а не то, что вы уже приняли его.
4. Откройте [библиотеку](https://github.com/agnstrv/plant-texture-library) и выполните её инструкцию первого запуска в Codex.

Можно попросить свой Codex: «Открой https://github.com/agnstrv/plant-library-access, прочитай README и отправь от моего GitHub-аккаунта заявку на доступ к библиотеке растений». Подключение GitHub в вашем Codex должно соответствовать вашему аккаунту.

Заявка публична. Достаточно стандартной формы; личные контакты, пароли и рабочие материалы прикладывать не нужно. Доступ включает чтение и пополнение библиотеки.

## Владельцу

Откройте [ожидающие заявки](https://github.com/agnstrv/plant-library-access/issues?q=is%3Aissue+is%3Aopen+label%3Aaccess-request). Проверьте, что автор — ваш коллега, и добавьте метку **access-approved**. Сценарий принимает одобрение только от владельца `agnstrv` (фиксированный GitHub ID), приглашает автора и закрывает заявку после успешной отправки.

- `invitation-sent` — приглашение отправлено; коллеге ещё нужно принять его.
- `access-already-granted` — аккаунт уже имеет доступ.
- `access-error` — приглашение не подтверждено. Откройте Actions; после исправления повторите запуск либо снимите и снова поставьте access-approved.
- Удаление access-approved до выполнения отменяет выдачу. После уже отправленного приглашения отзыв выполняется в настройках закрытой библиотеки.

Права записи в этот публичный репозиторий оставляйте только владельцу/доверенным администраторам. Коллегам достаточно создавать заявки. Код из PR и текст заявки не исполняются в процессе выдачи приглашений.

## Однократная активация

Автоматическая выдача требует отдельного fine-grained personal access token владельца. Обычный GITHUB_TOKEN видит только репозиторий заявок и не может приглашать в другую закрытую библиотеку.

1. [Создайте fine-grained token](https://github.com/settings/personal-access-tokens/new): Resource owner `agnstrv`, Repository access → Only select repositories → **plant-texture-library**.
2. Repository permissions → **Administration: Read and write**. Остальные дополнительные права не нужны; Metadata добавляется GitHub автоматически. Назовите ключ `plant-library-invitations` и выберите ограниченный срок действия, например 90 дней.
3. В [Actions Secrets этого репозитория](https://github.com/agnstrv/plant-library-access/settings/secrets/actions/new) сохраните его как **LIBRARY_INVITE_TOKEN**. В код, issue и чат ключ не вставляйте.
4. В [Actions → Library access](https://github.com/agnstrv/plant-library-access/actions/workflows/library-access.yml) нажмите Run workflow. Это проверяет подключение к закрытой библиотеке, никого не приглашая. Успешная проверка доступности репозитория ещё не заменяет первую реальную проверку приглашения.

После истечения ключа создайте новый с теми же правами и замените secret. Скрипт сообщает об ошибке и не утверждает, что приглашение отправлено.
